
# Date Extractor

A simple Python project to extract dates from text using Regular Expressions (Regex).

## Features
- Supports YYYY-MM-DD format.
- Supports DD/MM/YYYY format.
- Converts dates to YYYY-MM-DD format.
- Extracts multiple dates from text.
- Validates day, month, and year formats.
- Preserves the order of dates.

## Technologies
- Python
- Regular Expressions (Regex)
